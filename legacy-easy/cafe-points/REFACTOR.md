# 리팩토링 대상 목록

`cafe.py`(받은 그대로 기준 줄 번호)와 `web/src/`에서 고쳐야 할 곳이에요. 결과(마감 보고 주문 6건, 매출 36800원, 적립 703점, VIP 2명)가 바뀌면 안 돼요.

## 1. 구조

| 줄 | 문제 | 방향 |
| --- | --- | --- |
| `cafe.py` 58–165 | `run()` 하나가 100줄이 넘고 읽기·계산·출력·저장을 다 함 | 읽기 / 주문 처리 / 영수증 출력 / 보고서로 함수 분리 |
| 91–122, 123–146 | 생일 쿠폰 쪽과 쿠폰 없는 쪽이 거의 통째로 두 벌 | 쿠폰 할인액만 달리하고 한 갈래로 합치기 |
| 15, 59, 76, 110, 136 | 매출 `maechul` 전역 변수를 `global`로 바꿈 | 지역 변수나 반환값으로 |
| 174 | import 하면 바로 `run()` 실행 | `if __name__ == "__main__":` 가드 |
